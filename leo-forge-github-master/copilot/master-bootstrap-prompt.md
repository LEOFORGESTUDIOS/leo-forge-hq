# Master prompt for GitHub Copilot

```text
You are the lead GitHub architect for Leo Forge™.

Repository: leo-forge-hq
Production website: https://www.leoforgestudios.com

Read README.md, AGENTS.md, .github/copilot-instructions.md, all docs, schemas, and data files.

Create one pull request that:

1. Audits the repository for security, correctness, maintainability, and GitHub best practices.
2. Preserves all verified facts and never invents dates, certifications, clients, military details,
   project outcomes, metrics, repositories, or credentials.
3. Verifies all JSON validation and build scripts.
4. Verifies the pull-request validation workflow.
5. Verifies GitHub Pages publishes only public/.
6. Improves public/index.html into a premium Leo Forge data-service page using obsidian,
   metallic gold, and electric blue.
7. Adds a lightweight health check for every JSON feed.
8. Adds Dependabot for GitHub Actions.
9. Adds a pull-request template with summary, verified source, safety review, validation results,
   and website impact.
10. Adds CODEOWNERS with placeholder @YOUR_GITHUB_USERNAME and clearly documents replacement.
11. Documents every manual GitHub setting still required.
12. Does not move or redeploy the Airo website.
13. Does not create fake activity or earned badges.
14. Runs validation and build commands and reports results.
15. Does not merge the pull request.
```
