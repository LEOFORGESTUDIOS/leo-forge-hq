## What this repository does

- Stores public-safe project, certification, cyber-range, and Forge Log data.
- Publishes JSON feeds through GitHub Pages for the Airo website.
- Gives GitHub Copilot permanent project instructions.
- Validates public records before they are merged.
- Provides templates for case studies, labs, and certification logs.

## Public-safety rule

Never commit secrets, credentials, private network identifiers, guest or client data,
active-box solutions, restricted walkthroughs, confidential school work, or undisclosed
vulnerability details.

## Setup

1. Create the GitHub organization `LeoForgeStudios` if available.
2. Create a public repository named `leo-forge-hq`.
3. Upload this package.
4. Replace `YOUR_GITHUB_ORG` and `YOUR_GITHUB_USERNAME` placeholders.
5. Enable GitHub Actions.
6. In Settings → Pages, select GitHub Actions.
7. Give `copilot/master-bootstrap-prompt.md` to GitHub Copilot.
8. Review every pull request before merging.

## Public feed pattern

`https://YOUR_GITHUB_ORG.github.io/leo-forge-hq/api/<file>.json`
